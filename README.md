# ОИС — тренажёр

Карточки к итоговым экзаменам, два предмета (переключатель вверху главной):

- **ОИС** — «Обработка сигналов и изображений»: темы 1–10 (на экзамене будут они), 50 вопросов;
- **Embedded** — «Встроенные системы» (Embedded systems): 44 вопроса билета по 9 темам, у каждого вопроса — его
  номер из билета и узбекский текст.

Приложение для телефона (PWA): работает без интернета, прогресс хранится на самом телефоне.

Открыть: https://ascon5.github.io/ois-trainer/

## Как поставить на айфон

1. Открыть ссылку в **Safari**.
2. «Поделиться» → «На экран „Домой“».
3. На экране появится иконка «ОИС».

## Как учить

- **Учить**: 15 карточек. Вспомни ответ, открой его, нажми «Знаю» или «Не знаю».
- Ответил «Не знаю» — карточка вернётся через три другие и будет возвращаться, пока не вспомнишь. Чтобы она снова
  стала «знаю», её надо вспомнить ещё в одном заходе.
- **Трудные** — только карточки, на которых ошибался. **Случайный** — один вопрос наугад.
- Темы с прогрессом, учёба по одной теме, поиск по вопросам и ответам (в Embedded — и по номеру вопроса, и
  по-узбекски).

## Файлы

`data.js` — ОИС, `emb.js` — Embedded (ответы), `uz.js` — узбекский текст вопросов Embedded (из саволлар.docx),
`app.js` — логика, `app.css` — оформление, `sw.js` — офлайн-кэш (после изменения файлов поднять `VERSION`),
`manifest.webmanifest` и `icon-*.png` — иконка и установка на телефон.
